

## 环境启动

这个我一般会自己保证
```bash
# 启动平台，会打开一个网页
..\start.ps1

# 停止平台
..\stop.ps1
```

对于理想感知的情况(给出100%准的经纬度坐标)

| 入口 | 用途 | 特点 |
|---|---|---|
| `control_test_runner.py` | 基础控制实验 | ；通过 `--agent` 指定算法，输出评分和 `v1_summary.json` |
| `timing_study.py` | 单次详细实验 | 基于上面的 runner，额外保存逐帧观测、通信、裁判数据、源码快照；支持中断截图 |
| `run_timing_batch.py` | 批量实验 | 本身不实现仿真，每轮启动一次 `timing_study`，指定 `--revision working` |
| `nearest_selection_study.py` | 最近距离锁定机制专项实验 | 使用专门的诊断智能体，构造单机、静止车辆对照；不是正常运行 PersonalV1 |

```bash
# 官方 agent
.\run.cmd control_test_runner `
  --scenario-json ".\configs\scenarios\coop_decoy\static-decoys.json" `
  --agent "baselines.coop_distributed:CoopDistributedAgent" `
  --duration 600 `
  --output "..\output\control-test-ideal"

# myagent_v1 单次实验
# 输出路径根据实际修改
.\run.cmd control_test_runner `
  --scenario-json ".\configs\scenarios\coop_decoy\static-decoys.json" `
  --agent "personal_hf2026.personal_v1:PersonalV1Agent" `
  --duration 600 `
  --output "..\output\personal_v1\three_uav_$(Get-Date -Format 'yyyyMMdd_HHmmss')"

# myganet_v1 批量实验
# 输出路径根据实际修改
.\run.cmd run_timing_batch `
  --layout "..\output\personal_v1\test05-速度判别器\scenario_coop_decoy_prepared.json" `
  --runs 20 `
  --start-seed 1 `
  --duration 250 `
  --output "..\output\personal_v1\0913_am_250s"
```
