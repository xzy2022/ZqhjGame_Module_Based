

对于诱饵静止的场景的启动方式
```bash
# 启动平台，会打开一个网页
..\start.ps1

# 停止平台
..\stop.ps1

Push-Location '..'
.\python\python.exe -m competition run `
  --scenario coop_decoy `
  --scenario-json ".\ZqhjGame_Module_Based\configs\scenarios\coop_decoy\static-decoys.json" `
  --agent baselines.coop_distributed:CoopDistributedAgent `
  --duration 600 `
  --photo-mode off `
  --output ".\output"
Pop-Location
```
