### 完全不开启UE的相机渲染

```bash
# 结束当前完整平台，避免占用同一个 Redis 端口
..\stop.ps1

# 终端一，只启动 Redis
..\bin\redis-server.exe `
  --port 6379 `
  --bind 127.0.0.1 `
  --protected-mode no `
  --save "" `
  --appendonly no

# 终端二，完整推理
# 官方文件的说法如下
# PYTHONPATH=. python -m competition run --scenario 赛道名 --agent 模块名:Agent类名 --duration 仿真时长

# gpt的建议
Push-Location '..'
.\python\python.exe -m competition run `
  --scenario coop_decoy `
  --agent baselines.coop_distributed:CoopDistributedAgent `
  --duration 600 `
  --redis-host 127.0.0.1 `
  --redis-port 6379 `
  --photo-mode off `
  --output .\output\official-evaluation
Pop-Location
```

### 开启UE的相机渲染但不打开网页可视化

$env:OPENSIM_NO_OPEN_BROWSER = "1"
..\start.ps1

  --redis-port 6379 `
