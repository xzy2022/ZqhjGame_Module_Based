## 1.2 仿真平台定位与核心挑战
赛事平台是基于 C++ 底层、Python上层封装的实时无人集群仿真推演平台，专为受限信息 ISR 竞赛设计。参赛队伍仅可通过机载相机、有限编队通信获取局部观测，平台强制设置战争迷雾信息隔离机制，禁止任何全局上帝视角读取：
1. 无法直接读取队友无人机位置、探测结果；
2. 无法获取地面真实目标、诱饵真值坐标；
3. 无法直接读取静态 / 动态电磁干扰区精确位置；
4. 诱饵与真实目标皆可机动，需靠视觉特征判断。
参赛核心任务：实现智能体Agent，控制单 / 多架无人机，完成搜索→识别→持续盯防摧毁→目标坐标上报全链路自主闭环。

## 3.2 赛题二：多机协同识别（进阶赛道）
### 3.2.1 任务背景
3 架无人机分散部署，任务区域包含 3 台真实移动目标、15 台移动诱饵车。队伍需通过有限通信实现多机信息共享，协同区分诱饵与真实目标，完成目标清除与精准坐标上报。
### 3.2.2 环境约束
1.受控实体：3 架无人机，每台独立运行一套 Agent 算法；
2.目标配置：3 真目标 + 15 移动诱饵；
3.通信约束：通信距离没有约束、单条消息≤50 字节、发送频率≤4Hz；
4.仿真总时长：600 秒。
### 3.2.3 关键规则
1.协同盯防打击：≥2 架 UAV 同时盯防同一真目标累计 20 秒即判定摧毁目标。
2.目指上报：用 report_target(lat, lon) 上报判定为真目标的位置，按定位精度（RMSE）评分。

# 额外补充

## 真目标和诱饵的区别

真目标和诱饵都是无人车。当前场景配置中，
- 15 台诱饵全部配置为 speed=10 m/s、speed_jitter=1.5(速度扰动值)
- 3 台真目标都是 speed=10 m/s、speed_jitter=1.5

赛题启动代码明确为真目标和诱饵都分配并注入 A* 运动路线：
[runner.py (line 172)](../../../competition/sdk/scenarios/coop_decoy/runner.py:172)。但是这步规划和注入有可能失败(A* 超时)，如果失败，则对应无人车会静止。
